Extra Credit: Non-Identical Basketball Shots

1 1. Population Description

This simulation models a basketball player whose probability of making a shot decreases because of fatigue.

The observations are independent, but they are not identically distributed. The probability changes depending on the shot number. The first shot has probability (0.90) of being made, and the final shot has probability (0.50).

Each shot is a Bernoulli random variable:

\[X_t \sim \text{Bernoulli}(p_t)\]

The probabilities are different across shots, so this is an independent but non-identically distributed process.

2 2. Prediction Before the Simulation

Before running the simulation, I predict that the sampling distribution of the mean will become more approximately normal as the number of shots increases.

Because the probabilities change across observations, I expect the distribution to differ from an ordinary binomial distribution. I expect the sample means to be centered near the average probability of (0.70).

3 3. Simulation Design

3.1 Sample Sizes

I will investigate the sample sizes (n=5), (n=10), (n=20), (n=30), (n=50), and (n=100).

For each sample size, the shot probabilities decrease linearly from (0.90) to (0.50).

3.2 Number of Simulations

For each sample size, I will generate 10,000 repeated samples. Each sample will produce one sample mean.

sample_sizes <- c(5, 10, 20, 30, 50, 100)

B <- 10000

3.3 Reproducibility

I used the last four digits of my student ID as the random seed.

student_id <- 6424

set.seed(student_id)

4 4. Simulation Function

The following function creates a different probability for each shot and calculates the average result.

simulate_basketball_means <- function(n, B = 10000) {
  
  p <- seq(
    from = 0.90,
    to = 0.50,
    length.out = n
  )
  
  replicate(
    B,
    mean(
      rbinom(
        n = n,
        size = 1,
        prob = p
      )
    )
  )
}

5.3 5.3 Comparison of Histograms Across Sample Sizes

The average probability is (0.70) for every sample size.

The theoretical standard error is calculated using:

\[SE(\bar X) = \frac{\sqrt{\sum p_i(1-p_i)}}{n}\]

basketball_mean <- 0.70

old_par <- par(mfrow = c(2, 3))

for (n in sample_sizes) {
  
  x <- all_sample_means[[paste0("n_", n)]]
  
  p <- seq(
    from = 0.90,
    to = 0.50,
    length.out = n
  )
  
  theoretical_se <- sqrt(
    sum(p * (1 - p))
  ) / n
  
  hist(
    x,
    breaks = 30,
    probability = TRUE,
    main = paste("Sampling Distribution, n =", n),
    xlab = "Sample means",
    col = "lightblue",
    border = "white"
  )
  
  curve(
    dnorm(
      x,
      mean = basketball_mean,
      sd = theoretical_se
    ),
    add = TRUE,
    col = "darkblue",
    lwd = 2
  )
  
  abline(
    v = basketball_mean,
    col = "red",
    lwd = 2
  )
}
par(old_par)

The blue curve is the theoretical normal approximation. The red line marks the theoretical mean of (0.70).

6 6. When Did the Sampling Distribution Become Approximately Normal?

The sampling distribution became approximately normal at (n=30).

At (n=30), the histogram was roughly bell-shaped, and the Q–Q plot was mostly linear. The simulated mean was (0.6992), close to the theoretical mean of (0.70). The simulated standard error was (0.08075), close to the theoretical value of (0.08078).

Therefore:

\[\boxed{n=30}\]

7 7. Why Did I Choose That Value?

I chose (n=30) because it was the first sample size that provided clear evidence of approximate normality. The histogram was roughly bell-shaped, the Q–Q plot was mostly linear, and the skewness was relatively small at (-0.163).

8 8. What Surprised Me?

I was surprised that the sampling distribution became approximately normal even though the shot probabilities were different. The shots were independent but not identically distributed.

9 9. Conclusion

The sampling distribution became approximately normal at (n=30). The sample means stayed near (0.70), the simulated standard errors closely matched the theoretical values, and skewness and excess kurtosis moved closer to 0 as the sample size increased. This shows that normal approximations can still work when independent observations have different probabilities.
